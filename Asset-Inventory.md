# Asset Inventory

## Project Overview

This asset inventory was created for the fictional company **Botium Toys** as part of a cybersecurity risk assessment using the NIST Cybersecurity Framework (CSF).

The purpose of this inventory is to identify important business assets so security risks can be assessed and appropriate controls can be implemented.

---

## Asset Inventory

| Asset | Asset Type | Why It Is Important | Example Risk |
|-------|------------|---------------------|--------------|
| Employee laptops | Hardware | Used for daily work | Malware infection |
| Internal network | Network | Connects company systems | Unauthorized access |
| Customer database | Data | Stores customer information | Data breach |
| Credit card information | Sensitive Data | Used for online payments | Theft of financial information |
| Inventory management system | Software | Tracks products | System outage |
| Ecommerce website | Application | Allows online sales | Website attack |
| Warehouse inventory | Physical Asset | Products for sale | Theft or fire damage |
| Employee accounts | Digital Asset | Access to company systems | Account compromise |

---

## Key Assets

The most critical assets are:

- Customer database
- Credit card information
- Ecommerce website
- Internal network

These assets should receive the highest level of protection because they support business operations and contain sensitive information.

---

## Security Recommendations

Based on the asset inventory, the following controls would improve security:

- Implement Least Privilege.
- Enable encryption for sensitive customer data.
- Install an Intrusion Detection System (IDS).
- Maintain regular backups.
- Strengthen password policies.
- Implement a password management system.
