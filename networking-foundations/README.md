# Networking Foundations

This project documents my foundational networking and network-security learning as I prepare for entry-level IT support, IAM, and cybersecurity roles.

## Topics Practiced

- TCP/IP and IP addressing
- Public and private IP addresses
- DNS and DHCP
- Wi-Fi and VPN fundamentals
- Authentication versus authorization
- Basic network troubleshooting
- Network-security concepts, including least privilege and secure remote access

## What I Can Explain

- DNS helps translate a website name, such as google.com, into an IP address.
- DHCP automatically gives devices network settings such as an IP address, default gateway, and DNS server.
- A VPN creates an encrypted connection between a device and a remote network.
- Authentication confirms who a user is; authorization determines what that user can access.
